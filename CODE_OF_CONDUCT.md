# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, assume good faith, keep feedback about the work, and welcome people who are new to Codex, Claude Code, or open source. Harassment, personal attacks, and publishing others' private information are not tolerated.

Report unacceptable behaviour through GitHub's report feature or by opening a private security advisory on this repository. Maintainers will review and respond, and may remove, edit, or reject comments, commits, issues, and other contributions that do not align with this code.
